Util Menu

Retire Selected Cell

This item has been made available but is intended primarily for debugging purposes only.

Removes the selected cell from the system.

Note: The CellAppMgr will most likely add the removed cell back into the space when it performs its regular load balancing.

Stop Selected CellApp

This item has been made available but is intended primarily for debugging purposes only.

This item stops the CellApp process the currently selected cell resides on.
