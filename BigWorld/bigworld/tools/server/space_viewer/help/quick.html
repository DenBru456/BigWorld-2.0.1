Quick Reference

Action Description
Ctrl+Q Close space view window
Ctrl+L Warp to log event dialog
Ctrl+W Warp to time dialog
Ctrl+Home Zoom to space boundary
Ctrl+I Image overlay dialog
Ctrl+R Relative cell load colouring
Home Move playback to beginning of log file
End Move playback to end of log file
Up Arrow Moves playback 60 seconds backwards
Down Arrow Moves playback 60 seconds forwards
Left Arrow Moves playback 1 second backwards
Right Arrow Moves playback 1 second forwards
Page Up Zoom In
Page Down Zoom Out
Scroll Wheel Zoom In and Out
Left Mouse Select / Deselect cell to view within a space
Middle Mouse Rubber band zoom in
Right Mouse Select / Deselect cell to view within a space
