Replaying Data from SVLogger

When replaying data from SVLogger some new keys are used for navigating through the logs. The following list outlines the keys and their functionality:

  • LEFT ARROW: Moves the playback 1 second backwards.
  • RIGHT ARROW: Moves the playback 1 second forward.
  • UP ARROW: Moves the playback 60 seconds backwards.
  • DOWN ARROW: Moves the playback 60 seconds forward.
  • Home: Moves the playback to the beginning of the log.
  • End: Moves the playback to the end of the log.
  • Ctrl+L: Prompts the user to select a command log file. See below for more info.
  • Ctrl+W: Prompts the user to enter a time to warp the playback to.

Command Log Files

Command log files can be any file in which each line contains date / time string such as 'Thu Nov 17 17:45:45 2005'. These timestamps are used for navigating through a saved space log file.

Once a command file has been selected, the script will display all logged events contained in the log file, and prompt the user to select one.

Once a specific event has selected, playback time will be warped to the time of selected event.
